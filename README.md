## Info Build

Semua APK sudah di-proteksi:

- **R8/ProGuard obfuscation** - kode di-minify & nama class/method diacak, sulit di-decompile
- **Signed** - APK ditandatangani (SHA-256)
- **Optimized** - resource di-shrink, ukuran minimal

## Install

1. Download APK dari folder masing-masing
2. Install di Android (Android 7.0+ / minSdk 24-26)
3. Aktifkan "Install unknown apps" jika install di luar Play Store
