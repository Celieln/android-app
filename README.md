## Info Build

Semua APK sudah:
- **R8/ProGuard obfuscation** - kode tidak bisa mudah dibongkar/didecompile
- **Signed** - APK ditandatangani
- **Optimized** - ukuran dikompres & resource di-shrink

## Install

1. Download APK dari folder masing-masing
2. Install di Android (Android 7.0+ / minSdk 24-26)
3. Untuk install di luar Play Store, aktifkan "Install unknown apps"

## Teknologi

- Kotlin
- Android SDK 34
